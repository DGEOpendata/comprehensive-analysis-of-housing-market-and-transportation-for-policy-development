# Comprehensive Housing and Transportation Analysis

This project provides an integrated analysis of housing affordability and public transportation usage in Abu Dhabi, aimed at supporting policy development and urban planning.

## Prerequisites
- Python 3.x
- Pandas library
- Jupyter Notebook (optional for interactive exploration)

## Installation
To run this analysis, ensure you have Python installed along with Pandas. You can install Pandas using pip:
bash
pip install pandas


## Dataset
1. **Housing Affordability Index**: CSV file containing median income, home prices, and housing cost burden metrics.
2. **Public Transportation Usage Statistics**: JSON file detailing passenger counts, peak times, and frequented routes.

## Usage
- Load the datasets into pandas DataFrames.
- Merge the datasets using a common key such as 'region'.
- Perform analysis to extract insights, e.g., calculate average housing cost burden in regions with high public transport usage.
- Save the results to an Excel file for further exploration.

## Example Code
The provided Python script demonstrates loading, merging, and analyzing the datasets. Modify the file paths as needed to point to your dataset locations.

## Conclusion
This analysis equips stakeholders with a comprehensive perspective on urban dynamics in Abu Dhabi, facilitating informed decision-making in housing policy and transport planning.

For more detailed exploration, consider extending the analysis to include temporal trends or additional socio-economic factors.
